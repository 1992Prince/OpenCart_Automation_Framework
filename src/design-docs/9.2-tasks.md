# GitHub Actions / CI-CD – Tasks & Questions

### 0) Test Tags + Package.json

* First tag the tests: `@smoke`, `@sanity`, `@regression`.
* Add commands in `package.json`.
* Run locally using `npm`.
* Use the same commands in CI.

### 1) Cache

* Run one workflow successfully and validate the cache under **Actions**.
* If the workflow fails, cache will not be saved.
* Cache helps avoid downloading **Node modules and Playwright browser binaries** again.
* If `package.json` changes, a new cache will be created.

### 2) GitHub Environments & Secrets

* Create different environments: `DEV`, `QA`, `STG`, `PROD`.
* Create environment-specific secrets.
* If `STG` is selected → only STG secrets should be used.
* Similarly for other environments.

---

# My Pipeline Information

* Same pipeline can be run against different environments.
* Secrets are fetched from the **selected environment**.
* Tests run against the selected environment using `@smoke`, `@sanity`, or `@regression` tags and a specific Playwright project.
* Cache is used for Node modules and Playwright browser binaries.
* Test results, HTML reports, screenshots and other artifacts are uploaded.
* HTML report/dashboard is published to **GitHub Pages**.
* Dashboard link is shared through email and Slack.
* Pipeline summary shows:

  * Total tests
  * Passed
  * Failed
  * Skipped
